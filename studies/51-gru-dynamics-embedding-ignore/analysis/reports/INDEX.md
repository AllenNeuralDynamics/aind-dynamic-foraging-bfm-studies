| [r1](r1-first-look.md) | first-look | draft (B1–B8) | Side prediction and side updates unchanged from C; engagement on its own near-orthogonal direction (PC2) carried by largely separate units, with a fifth state cluster after an ignore that still carries the side belief; an ignore decays side preference symmetrically (~30%) and pushes hard and lastingly toward disengagement, a reward pushes briefly toward engagement; teacher-forced engagement is calibrated, including the bout-exit hazard |

| [r6](r6-integration-axis.md) | integration-axis | draft (I1–I4) | The TDR value coordinate is carried through ignores as through every engaged input (slope 0.62–0.84, R² 0.95–0.99; same value axis with or without ignores in the fit, cos 0.997) — what an ignore removes is the readout's last-choice offset (corrects "shrinks toward neutral", which holds for the readout only); C's two-lobe side axes kept; the post-ignore cluster holds a shrunken side value on a between-lobe axis; one rule v ← 0.71·v per ignore recovers 83% of C3's post-ignore edge over C in a distilled model run on inputs alone; engagement distils into a second, nearly decoupled variable (87% of its gain over base rate) |
