Why the samples that fit so far dominate: the algebra

Write pt(θd) for the probability sample d gives the choice actually made on trial t, running the session by teacher forcing with its fixed parameter θd (D samples, T trials). The score averages each sample's whole-session likelihood:

1D∑d=1D∏t=1Tpt(θd)

Nothing is reweighted in that computation. But the same number can be split into one factor per trial:

=∏t=1T∑dwd(t)pt(θd)∑dwd(t),wd(t)=∏s=1t−1ps(θd)

Each factor is the prediction for trial t: an average of the samples' predictions, weighted by wd(t), each sample's likelihood of the earlier trials 1,…,t-1. With the slider at trial t, the left panel's dot sizes are wd(t+1): the weights for predicting the next trial, t+1, from trials 1,…,t. No future trial ever enters a weight.

Why the two expressions are equal (derivation)

Name the total weight before trial t:

St=∑dwd(t)

Before any trial the product defining the weight is empty, so wd(1) = 1 and S1 = D. After the last trial, wd(T+1) is sample d's whole-session likelihood, so the score is

1D∑d∏tpt(θd)=ST+1S1

Each trial multiplies every weight by one more factor, wd(t+1) = wd(t) pt(θd). Summing over samples,

∑dwd(t)pt(θd)=St+1

so factor t of the split is St+1 / St, and the product telescopes: each numerator cancels the next denominator.

∏t=1TSt+1St=S2S1⋅S3S2⋯ST+1ST=ST+1S1

This is an exact identity, not an approximation. It is the sample version of the chain rule, p(y1:T) = ∏t p(yt | y1:t−1): factor t estimates the posterior-predictive probability of choice t given the choices before it.

None of this is new. Scoring a model by its one-step-ahead predictions is Dawid's prequential analysis [1], and averaging whole-session likelihoods over fixed parameter samples is sequential importance sampling: a particle filter for a static parameter that never resamples, whose evidence estimate is this product of normalised weight increments [2].

Per-trial averaging (the grey dashed line) keeps every weight equal on every trial:

∏t=1T1D∑d=1Dpt(θd)

That is a product of averages, not an average of products: no sample ever gains from having explained earlier trials, and the result is not the probability of the session under any single sample.

Reading the right panel: each line is the geometric mean of the predicted probabilities of the trials so far. The zero-spread and full lines average each sample's whole-session likelihood, then split that average by trial; per-trial averaging (grey dashed) averages each trial's probability separately, then multiplies.
The dots growing and shrinking on the left is not the code changing weights. The code does one thing: hold each sample's parameter fixed, run the whole session by teacher forcing, and average the whole-session likelihoods. Dot size is only an equivalent reading of that average: when it is split by trial, each sample's implied share of the next trial's prediction equals its likelihood of the earlier trials. Both readings give exactly the same number.
