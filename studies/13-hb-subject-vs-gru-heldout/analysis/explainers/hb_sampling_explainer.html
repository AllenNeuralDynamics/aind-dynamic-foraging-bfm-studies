How one mouse's held-out session is scored: plug-in / zero-spread / full

Toy model: a single parameter (learning rate α), fixed softmax temperature, no bias, no forgetting. The data are simulated.
⚠ An illustration, not study 13's data. The computation is the same as the real scoring: average each sample's whole-session likelihood.

Samples (each dot = one candidate α; dot size = its implied weight so far)

Average per-trial likelihood up to trial t (higher is better)

Reading the right panel: each line is the geometric mean of the predicted probabilities of the trials so far. The zero-spread and full lines average each sample's whole-session likelihood, then split that average by trial; per-trial averaging (grey dashed) averages each trial's probability separately, then multiplies.
The dots growing and shrinking on the left is not the code changing weights. The code does one thing: hold each sample's parameter fixed, run the whole session by teacher forcing, and average the whole-session likelihoods. Dot size is only an equivalent reading of that average: when it is split by trial, each sample's implied share of the next trial's prediction equals its likelihood of the earlier trials. Both readings give exactly the same number.
