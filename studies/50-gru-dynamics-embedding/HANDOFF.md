## 7. Working conventions and gotchas

**How the user wants to work:**
- Straightforward analyses first; side-by-side panels rather than overlays.
- PCs 1–4 by default.
- Don't commit until asked.
- State what is by construction vs a finding.
- Correct earlier claims explicitly when new results change them (as in r6 items 6 and
  10).

**Study conventions:**
- One producer per artifact.
- Frozen JSON with `_meta` via `s12.write_json`.
- Figures saved as `analysis/fig_*.png` via `s12.figure_path`.
- Exploration outputs go under `_cache/explore/`.
- Every new script gets a Makefile target, a FIGURES.md entry, a CHANGELOG line and its
  report section.

**Data conventions:**
- **Trial-row timing:** row t's state has seen trial t−1 and predicts trial t.
- **GRU input tensor:** `xs[τ]` carries trial τ−1's outcome; τ = `trial_idx − 1`.
- **Tasks** come from the session table's `task` column, not from curriculum labels.

**RL baselines:**
- **Study 01's group names:** its script hardcodes wrong group suffixes; use the groups in
  `source_runs.json`.
- **Hattori Q values** come from per-session agent replays; the shared-Q fallback gives
  wrong values for two-learning-rate agents.
- **Policy:** P(right) = σ(β(Q_R − Q_L) − biasL), plus β·w_ck·(CK_R − CK_L) for Bari.
- **Bari's choice kernel** has step size 1, so it is the last choice only.

**Pitfalls already hit:**
- The `Hattori2019` logistic design is rank-deficient; use Su2022.
- Conditioning on the outcome being scored inflates "switch-trial" advantages; split on
  pre-choice quantities.
- Global-mean ablations go off-manifold; use conditional means with random controls.
- Fixed points need float64, forward iteration and damped Newton (wrapper
  `find_fixed_points`).
- Pass large arrays to joblib as memmapped arguments, not closures.
- Guard spawn pools (AGENTS.md §5).

**AGENTS.md rules that apply:** load the relevant skills first (study-conventions,
posthoc-reporting, wrapper-runtime); human-facing timestamps in Seattle time with W&B
links.
